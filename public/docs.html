API documentation

Add link-safety scanning to your product with two REST endpoints — completely free. Create an account, generate a key in the dashboard, and you're live in minutes.

Authentication

Pass your API key in the X-Api-Key header on every request. Keys look like lak_… and can be created and revoked from your dashboard.

X-Api-Key: lak_your_key_here

Limits

The API is free. Each key allows 1,000 scans per calendar month — a fair-use cap so no single key drains the shared threat-feed budget, not a paywall. There is no paid tier that raises it; if you have a legitimate need for more, just ask.

Every response includes X-Quota-Limit and X-Quota-Used headers. Exceeding the limit returns 429, and it resets on the 1st of each month.

POST/api/v1/scan

Scans a URL and returns the full analysis.

Request

curl -X POST https://your-domain.com/api/v1/scan \
  -H "X-Api-Key: lak_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/some-link"}'

Errors

  • 400 — invalid or missing URL
  • 401 — missing, malformed, or revoked API key
  • 429 — monthly quota exceeded

GET/api/v1/usage

Returns your current month's usage across all keys.

curl https://your-domain.com/api/v1/usage \
  -H "X-Api-Key: lak_your_key_here"

{ "month": "2026-07", "used": 42, "quota": 10000 }

Verdict guidance

  • safe (score < 25) — no significant indicators; treat as low risk.
  • caution (25–59) — one or more suspicious traits; warn the user.
  • dangerous (score ≥ 60) — strong phishing/malware indicators; block or strongly warn.

Fair use

Automated scanning of links you receive (email pipelines, chat moderation, form validation) is exactly what the API is for. Don't use it to probe infrastructure you don't own or to harass third-party services.
